# Промты для изображений — «Использование и охрана полезных ископаемых», 3 класс

Общие правила:
- Промты на английском — генераторы понимают их точнее.
- Для персонажа прикладывай свою картинку с девочкой как референс (image reference / character reference), чтобы она была одинаковой на всех кадрах.
- Персонажа, минералы и предметы генерируй на **чисто белом фоне** (или на прозрачном, если генератор так умеет). Фон я вырежу сам.
- Присылай с кодом (C1, P3, M5…) в сообщении или в имени файла. Можно частями.
- Обязательные помечены ★, остальные по желанию (если их не будет, поставлю иконки).
