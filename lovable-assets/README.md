# Ассеты сайта «Кладовые Земли» (Lovable)

Картинки, звуки и тайминги физкультминутки для сайта урока «Использование и охрана полезных ископаемых». Сайт на Lovable берёт их отсюда через jsDelivr.
Звуки — Mixkit (бесплатная лицензия), голос — нейросеть (Microsoft Neural TTS), картинки — OpenART и Figma.
